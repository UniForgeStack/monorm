# monorm

The same package as [`@ufstack/monorm`](https://www.npmjs.com/package/@ufstack/monorm).
It depends on `@ufstack/monorm` at the same version and re-exports it, so `import "monorm"` and `npx monorm` give the same result.
Install the native profile and the extension packages under their `@ufstack/` names.
