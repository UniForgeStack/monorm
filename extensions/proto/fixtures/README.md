# Fixture messages

The `.proto` files are the source of the generated test classes.
The generated code is committed. Run `extensions/proto/fixtures/generate.sh` to rebuild it.

- Python (Google protobuf): `languages/python/tests/proto_gen/`.
- TypeScript, protobuf-es v2: `languages/js/test/proto/gen/`.
- TypeScript, ts-proto: `languages/js/test/proto/gen-ts-proto/` (one file: `acme/note.ts`).
